# Mở data warehouse

- **docker start postgres**-**dwh**-**vna**-**wom**

# Tắt data warehouse

- **docker stop postgres**-**dwh**-**vna**-**wom**

# Check data warehouse

- docker ps -a --filter "name=postgres-dwh-vna-wom"

   * **Host:** `localhost`
   * **Port:** `5432`
   * **Database:** `vna_wom_dev`
   * **Username:** `postgres`
